# Illustration generation notes

Date: 2026-09-02

All six assets were generated as original artwork for this project, visually inspected during generation, converted to responsive WebP files, and inspected again inside the working quiz at desktop and mobile sizes.

## Final assets

- `public/art/quiz-curiosity.webp`
- `public/art/quiz-choice.webp`
- `public/art/quiz-strategy.webp`
- `public/art/quiz-collaboration.webp`

## Transformation

The generated PNG originals were preserved in the Codex generated-image store. Each final asset was resized to a maximum width of 1280 pixels without enlargement and converted with Sharp to WebP at quality 84 and effort 5. The resulting six-file set is approximately 1 MB.
